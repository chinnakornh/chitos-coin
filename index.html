Multisig Custody

Six separate Safe multisig beneficiary wallets have been deployed using Safe 1.4.1. Each wallet requires two of three authorized owners to approve transactions. All six wallets use the same three owners.

View Contract Directory →

Token Contract Design

CHTC uses an ERC-20-compatible token implementation on BNB Smart Chain with 18 decimals, burn and permit support. The deployed token has no additional minting function, transfer tax, owner-controlled blacklist or upgrade mechanism.

Development & Security

Reported testnet checks passed 164/164, including allocation reconciliation, early-release rejection and vesting boundary calculations. Two-owner Safe execution and single-signature rejection were tested on testnet. Actual post-unlock release and remaining security review are incomplete.

Risks & Legal Notice

CHTC is experimental. Smart contract defects, loss of keys, irreversible transfers, market volatility, illiquidity and regulatory changes may cause total loss. Obtain jurisdiction-specific legal advice before public distribution, marketing or trading, including applicable Thai digital-asset requirements.

Source code verification is not a security audit. No independent audit has been completed. Shared-device signer storage creates correlated compromise risk. Independent devices or hardware wallets are recommended for production custody.
