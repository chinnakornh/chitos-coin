Token architecture

CHTC is a BEP-20 compatible token implemented using OpenZeppelin contracts.

  • Initial supply: 1 billion CHTC
  • 18 decimals
  • No additional mint function
  • No transfer tax
  • Burn support
  • ERC-2612 permit support
  • Non-upgradeable token contract
  • No privileged token administrator

Token burning may reduce the total supply.

Custody and transparency

Six separate Safe multisig wallets have been deployed as designated beneficiaries, using the same three signers with a two-signature threshold.

Signer storage on one computer creates correlated compromise risk. Independent devices or hardware wallets are recommended before public launch.

Vesting beneficiaries and schedules are immutable in the deployed vesting contracts.

Development and security status

Reported testnet checks passed 164/164, including allocation reconciliation, early-release rejection and vesting boundary calculations.

The final Mainnet deployment script reported 6,087 passed checks and zero failures at initial distribution completion.

Actual post-unlock release testing, third-signer execution and remaining security review are incomplete. Script checks and source verification are not independent security audits.
